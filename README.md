# Description
This project is an online payment and request system for the Basc Registrar office and for students 
 BASC Registrar Online Payment and Request System is a web-based platform designed to simplify and speed up administrative transactions for Bulacan Agricultural State College (BASC). Built for both students and registrar staff, the system replaces long physical queues and paper-based processes with an efficient, fully digital solution.

Key Features

Online Document Requests: Allows students to easily apply for official academic documents—such as Transcripts of Records (TOR), Diplomas, and various certifications—anytime and anywhere.

Integrated Online Payments: Features a secure payment portal that lets students settle administrative fees directly online, eliminating the need to wait in line at the cashier's office.

Real-time Status Tracking: Enables students to monitor the status of their requests in real time, from submission and payment verification to final release.

Registrar Admin Dashboard: Gives registrar personnel a centralized dashboard to track incoming requests, verify payments, update document statuses, and manage workflow smoothly.
